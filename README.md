Sales Dashboard Analysis (Excel)
This project showcases an interactive Sales Dashboard built using Microsoft Excel. It focuses on analyzing sales performance across multiple dimensions such as time (yearly and monthly), product categories, and customer segments.

The project serves as a stepping stone in my data analytics journey, demonstrating how Excel can be used to transform raw data into actionable insights.

Objectives
Analyze sales trends from 2023 to 2027
Identify seasonal patterns and peak sales periods
Evaluate category-wise performance
Understand customer contribution

Tools Used
->Microsoft Excel
  ->Pivot Tables  
  ->Pivot Charts
  ->Slicers (Filters)
  ->Data Cleaning & Formatting
  ->Aggregations & Calculations
Dashboard Features
 Year-wise Sales Analysis – Track overall performance trends
 Monthly Sales Breakdown – Identify seasonality and fluctuations
 Category-wise Insights – Electronics, Furniture, Office Supplies
 Top Customers Analysis – Contribution distribution
 Interactive Slicers – Filter data dynamically by year and category

Key Insights
 Sales show steady growth from 2023 to 2026, but this alone does not confirm business stability without supporting metrics like profit or customer growth.
 A decline is observed in 2027, which should first be validated for data completeness before attributing it to external economic factors.
 Peak sales in Month 8 indicate possible seasonality; however, this trend should be confirmed with multi-year data to rule out one-time spikes.
 Electronics is a consistent revenue contributor, but without geographic data, no conclusions can be drawn about regional demand.
 Furniture shows high variability in performance, likely due to its high-value and infrequent purchase nature, though this requires validation with additional data (e.g., discounts or buying cycles).
 Customer contribution appears evenly distributed, suggesting lower dependency risk, but deeper analysis (e.g., retention, long-tail customers) is needed to confirm this.
 Learning outcomes
  Developed hands-on experience with Excel as a data analysis tool
  Gained understanding of data visualization best practices
  Learned how to extract actionable insights from structured data
